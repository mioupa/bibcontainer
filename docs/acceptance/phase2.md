## 1. 受け入れ基準（AT-S1〜S8）

テストはすべて `crates/sync/tests/` にある。AT-S1〜S6・S8 は、メモリ上の同期フォルダとローカルフォルダの両方で実行する。

| ID | 内容 | 確認方法 | 状態 |

| AT-S1 | 端末 A で 10 冊登録 → B に反映 | `acceptance.rs::at_s1_ten_books_registered_on_a_appear_on_b`。アプリを 2〜3 個起動した確認でも、登録から約 7.5 秒で相手の DB に届いた（0016） | 自動で確認済み。Google Drive 経由はユーザーの実機確認待ち |
| AT-S2 | オフラインで別々の項目を変更 → 両方残る | `acceptance.rs::at_s2_different_fields_changed_offline_both_survive` | 自動で確認済み |
| AT-S3 | 同じ項目を変更 → HLC が新しい方にそろう | `acceptance.rs::at_s3_same_field_the_newer_hlc_wins_on_both` | 自動で確認済み |
| AT-S4 | 削除の後の別端末の変更 → 削除のまま | `acceptance.rs::at_s4_deleted_stays_deleted_when_the_other_edits_later` | 自動で確認済み |

## 3. 実機確認チェックリスト（Google Drive を使った Mac と Windows の間）

準備: Mac と Windows の両方に Google Drive for desktop を入れ、同じアカウントでログインしておく。ストリーミングモードの場合は、同期に使うフォルダを「オフラインで使用可能」にしておく。

### 設定

- [ ] S01（Mac）設定 > 同期で、Google Drive の「マイドライブ」の下のフォルダ（例: `マイドライブ/本`）を選ぶ。「新しいライブラリを作る」を押すと、上部バーに同期の時刻が出る。フォルダの中に `bibcontainer-library/` ができる（FR-SYNC-01／09）
- [ ] S02（Windows）同じフォルダ（例: `G:\マイドライブ\本`）を選ぶ。見つかった端末に Mac が出る。参加すると、Mac の蔵書と書影が入る（AT-S6）
- [ ] S03 設定 > 同期で、端末名を変えられる。相手の端末の一覧に新しい名前が出る（FR-CONF-01）
- [ ] S04 別の空のフォルダや、別のライブラリのフォルダを選ぶと、理由が表示されて付け替わらない（AT-S8）

### ふだんの同期

- [ ] S05 Mac で本を登録する（スキャンでも手動でも）。Windows に数秒〜数十秒で届く。逆向きも（AT-S1）
- [ ] S06 書影のある本を登録する。相手の端末で、少し遅れても書影が表示に切り替わる（あとから届いた書影の再表示）
- [ ] S07 両端末で同じ本の別の項目を変える（例: Mac で評価、Windows で保管場所）。両方の変更が残る（AT-S2）
- [ ] S08 両端末で同じ本の同じ項目を変える。最後に変えた方にそろう（AT-S3）
- [ ] S09 片方で本をゴミ箱に移し、もう片方でその本の評価を変える。ゴミ箱のまま（AT-S4）
- [ ] S10 片方をオフライン（Wi-Fi を切る）にして数冊登録・編集し、オンラインに戻す。両方の変更がそろう（FR-SYNC-05）
- [ ] S11 登録した直後に ⌘Q（Windows はウィンドウを閉じる）で終了する。相手に届く（FR-SYNC-07）
- [ ] S12 上部バーの同期の表示が、状態（同期中、時刻、未書き出しの件数、エラー）に応じて変わる。押すと設定の同期の節が開く（FR-SYNC-08）

### 異常と復旧

- [ ] S13 Google Drive for desktop を終了する（または Drive を切断する）。同期の表示がエラーになるが、本の登録・編集は続けられる。Drive を戻すと自動で復帰する（10.2）
- [ ] S14（Windows）Drive のドライブ文字やフォルダの場所が変わった場合、設定 > 同期の「同期フォルダを選び直す」で新しい場所を選ぶと、解除せずに付け替わる
- [ ] S15 手元に本がある端末で、既存のライブラリに「統合」で参加する。両方の本が残る
- [ ] S16 手元に本がある端末で、「置き換え」で参加する。確認のあと、バックアップができ、一覧がライブラリの内容に入れ替わり、スキャン・表示の設定は残る
- [ ] S17 同期を解除する。手元の蔵書と同期フォルダの中身は残る。同じフォルダを選び直すと再び同期できる
- [ ] S18 設定 > バックアップから復元する。同期が自動で再開し、ほかの端末の変更がもう一度取り込まれる（0013 §10）
- [ ] S19 片方の端末の時計を 10 分以上進めてから変更し、同期する。もう片方に「時計が進んでいます」の警告が出る（FR-SYNC-11）

### 書影の整理と負荷

- [ ] S20 書影が数百冊以上ある蔵書で、新しい端末の最初の同期にかかる時間と、その間に画面が固まらないこと
- [ ] S21 設定 > 同期の「使われていない書影を整理」が動き、件数が表示される（FR-SYNC-13）
- [ ] S22 ファイル監視の通知が届く場合は数秒で、届かない場合でも 60 秒以内に、相手の変更が取り込まれる（Mac と Windows の両方。FR-SYNC-06）

### 見た目

- [ ] S23 設定の同期の節（手順、端末の一覧、警告、Google Drive の注意書き）と上部バーの表示が、ライト・ダークの両方で崩れていない
